# F1 — din gjennomføring

**STOPPET av Mads 2026-10-24. Ikke gjennomfør måling eller Start analyse. Serveren er stoppet, tidligere arming er ugyldiggjort. Se [dokumentsporing og caseegnethet](story-4-5-f1-dokumentsporing-2026-10-24.md).**

1. **Åpne** et blankt notat. Ha `tests/fixtures/property-cases/F1-tilstandsrapport.pdf` klar. Start skjermopptak med **Skift–Cmd–5**, slik at PDF, notat og senere apphandlinger er lesbare. Behold originalopptaket.

2. **Manuell vurdering først:** Tiden starter idet du åpner F1-PDF-en for å lese den. Les hele rapporten uten KI-listen. Noter TG2/TG3, beskrivelse, fysisk PDF-side og eventuell usikkerhet. Kontroller notatene mot originalen. Tiden stopper når listen er ferdig kontrollert og du skriver **«Manuell kontroll ferdig»** i notatet. Behold notatet.

3. **Åpne live-appen:** http://127.0.0.1:3000 i Chrome. Klargjør F1: P **16000000**, L **1900000**, D **400000**, J **800000**, Ymin **7 %**. L/D/J er årsbeløp for 2026; bruk kontrollerte egne forutsetninger og appens kostnadskontroll. Bekreft tallgrunnlaget og last opp F1-PDF-en. Denne klargjøringen inngår ikke i analysetiden.

4. **Analysetiden starter** ved ditt ene klikk på **«Start analyse»**. Gå til **«Kontroller funn»** når analysen er ferdig. **Analysetiden stopper og kontrolltiden starter** når den ferdige listen med sider og eventuell usikkerhet faktisk er synlig.

5. **Kontroller selv:** Les originalsidene, se etter oversette funn, korriger/avvis ved behov og bekreft funnene. Håndter eventuell TG3 uten å tvinge frem Avklart. Vurder eventuelle generelle begrensninger med egen begrunnelse bare når du faktisk har kontrollert dem. **Kontrolltiden stopper** ved vellykket **«Bekreft gjeldende liste»**, etter at all kontroll er ferdig. Trykk deretter **«Beregn og vis resultat»**, film resultatet og avslutt opptaket. Ved feil: film feilen og stopp; ikke prøv på nytt.

6. **Send tilbake:** hvor originalvideoen og notatet ligger, faktisk anbefaling og eventuelle feil/avbrudd. Jeg henter **manuell tid, analysetid og kontrolltid** fra opptaket og fyller resten av beviset. Hvis du har egne stoppeklokketider, send de tre varighetene i sekunder også. Stopp etter F1.
