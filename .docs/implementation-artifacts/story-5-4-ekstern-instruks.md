# Til ekstern testperson

Bruk den rene lokale kopien og versjonen Mads oppgir. Følg **bare README.md**
for installasjon, hele F1–F4-demoen og alle oppgitte tester. Sperr eksternt
nett under demoen etter installasjon/browserforberedelse; behold localhost.
Noter miljø, versjon, kommandoer, faktiske utfall og alt uklart eller feilet
i [registreringsmalen](story-5-4-forberedelse-2026-10-27.md#bevismal--ingen-observasjoner-registrert).
Malen er bare for loggføring; README er fortsatt eneste kjøreoppskrift.
Be om at uklarheter registreres som avvik fremfor muntlig oppskriftshjelp.
Lever loggen til Mads. Ikke bruk API-nøkkel eller betalt konto.
