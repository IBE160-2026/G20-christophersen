# Redaksjonell strukturkontroll

PRD-en skal hjelpe Mads og etterfølgende BMAD-faser å bruke godkjent v1 som konkret, testbart kravgrunnlag. Strukturmodell: strategisk/pyramide for hoved-PRD, referansemodell for addendum. Ordgrunnlag fra BMAD word_metrics: PRD 7 392 ord, addendum 3 222 ord ved gjennomgangen.

| Pass | Original Text | Revised Text | Changes |
|---|---|---|---|
| structure | «Formål og arbeidsstatus» (82 ord); godkjenninger og avklaringsstatus fordelt i dokumentet | CONDENSE med samlet innledende status, avklarte krav og gjenstående produktverifikasjon | Gjør faktisk dokumentstatus tydelig før detaljer. Omtrent uendret ordmengde; ingen produktendring. |
| structure | PRD med 18 FR-er, fem NFR-er og seks suksesskriterier | PRESERVE kravgrupper, ID-er og godkjente kriterier | Detaljene og relevante gjentakelser støtter kontroll og videre KI-arbeid; ingen bred forkorting. Ordvirkning 0. |
| structure | Addendum med separate TG3-, RT-, BT-, AT- og S5-tabeller | PRESERVE oppdeling og test-ID-er | Testene følger kravgruppene og skiller protokollfasit fra produktresultater. Ordvirkning 0. |

Status: Innledende status er tydeliggjort ved ferdigstilling. Ingen krav kuttes eller omdefineres.
