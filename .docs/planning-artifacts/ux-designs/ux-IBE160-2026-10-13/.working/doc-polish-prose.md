# Redaksjonell språkkontroll

BMAD Review `lenses=prose`, etter [strukturkontrollen](doc-polish-structure.md), som dokumentstandard i BMAD UX. Dato: 2026-10-14. Grunnlag: [samlet dokumenttekst](doc-polish-input.md). Leser: mennesker. Stilguide: Microsoft Writing Style Guide. Innhold og beslutninger er bevart.

Dokumentene skal hjelpe menneskelige lesere å utforme og etterprøve den avklarte desktop-opplevelsen for v1. Bevar den nøkterne fagstemmen, kompakte tabellformuleringer, etablerte UX-termer, komponent-ID-er og navngitte brukerforløp.

Åtte forslag; anvendelsesstatus dokumenteres i sluttkontrollen. Ingen produktkrav, designvalg eller gyldighetsregel er vurdert på nytt i denne språkkontrollen.
