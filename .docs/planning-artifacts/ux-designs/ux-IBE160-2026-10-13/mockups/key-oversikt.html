Property Acquisition Agent — visuelle referanser

Fire statiske arbeidsflater illustrerer den valgte sekvensen. Åpne hver referanse for hovedvisning og utvalgte tilstander. Tall og rapportinnhold er konstruerte PRD-eksempler.

Dette er UX-artefakter. Handlingene er illustrerte; ingen rapport analyseres eller resultat beregnes her. DESIGN.md og EXPERIENCE.md definerer kontrakten.

  1. 1

    Tallgrunnlag

    Fem finansverdier, periode og kilde, kontrollerbart kostnadsinnhold og eksplisitt bekreftelse. Lokal variant med manglende leieinntekt.

  2. 2

    Tilstandsrapport

    Valgt dokument før Start analyse, tydelig demo-/live-opphav og separate laste- og analysefeiltilstander.

  3. 3

    Kontroller funn

    Funn og PDF side om side, separate kontroll-/avklaringsstatuser, korrigeringsutkast og PDF-panel ved smal desktop/zoom.

  4. 4

    Resultat

    En begrunnet anbefaling, fire nøkkeltall og tilgjengelig detaljsporbarhet. Egen variant viser et historisk, utdatert resultat.
