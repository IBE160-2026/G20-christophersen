# Story 2.7 — sekvensiell build-agent i mini-sprint

Dato: 2026-10-20. Hovedbestilling og faserekkefølge står i
[orkestratorloggen](2026-10-20-mini-sprint-2-5-2-7.md). Denne agenten var alene
aktiv som subagent. Ingen nestet/parallel delegasjon eller push.

BMAD-build SKILL.md ble lest og render-kommandoen kjørt nøyaktig én gang.
Rendret clarify/plan/implement/review/present, specmal og sprint-sync ble
fulgt innen brukerens allerede autoriserte fase 4. Menystopp og skildenes
parallelle delegasjon ble overstyrt av denne konkrete bestillingen. Interne
linser er egenkontroll; en ny agent må gjøre uavhengig full review før done.

Autoritet: epics.md Story 2.7 AC1–AC5, Epic 2-kontekst, 2.6 done-spec,
ARCHITECTURE-SPINE, SPEC/grensekontrakter, DESIGN/EXPERIENCE og gjeldende
sprintplan/status. Original sensorveiledning ble lest via lokal PDF.js-
tekstekstraksjon; faglærertilbakemelding og kursavstemming ble lest. Ingen
nytt kurskrav eller produkt-/arkitekturbeslutning ble lagt til.

Viktige agentstyringer: bruk ekte originalbytes, men send en egen kopi til
worker for å bevare originalidentitet; ny canvas per async render; synlig
kjent side-/visningsfeil uten gjetting eller analyse; behold 2.6s listestart-
og kunngjøringsvern; bare 2.7, ingen 2.8/2.9/TG3/Resultat/live.

[Spec og interne triagefunn](../../implementation-artifacts/spec-2-7-kontrollere-funnets-kilde-i-original-pdf-og-smalt-panel.md)
og [AC-/testbevis](../../implementation-artifacts/story-2-7-verifikasjon.md)
viser hva som ble endret og rettet. Første fullregresjon ga rødt på native
modalfokus etter siste kontroll; samme E2E går grønn med eksplisitt Tab/
Shift+Tab-felle. Kontraktlesing rettet også det valgfrie originalhashfeltet.

Endelig kjøring: `npm test`, `npm run typecheck`, `npm run lint`,
`npm run build`, `npm run test:e2e`: 505 Vitest, 66 bygget-app og 2 dev-E2E
bestått. Kun loopbackkjøring krevde miljøets autoriserte sandboxeskalering.
Fire representative bilder er lagret og visuelt lest; tastatur/panel/race/
feil/cleanup/offline er prøvd i faktisk bygget Chromium-app.

Checkpoint: Story 2.7 review, Epic 2/SP2 pågår, 2.8 backlog. Neste steg:
separat uavhengig full BMAD code review av reviewcommitten. Ingen blocker.
