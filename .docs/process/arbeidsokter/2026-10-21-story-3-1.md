# Story 3.1 — sekvensiell implementeringsagent

Brukerbestillingen er én kontrollert kjede: 2.8 → separat review → 2.9 → separat
review → 2.10 → separat review → 2.11 → separat review/full Epic 2-regresjon →
eventuelt 3.1 → separat review → eventuelt 3.2 → separat review og sluttregresjon.
Stopp før 3.3. Ingen parallelle filendringer, ingen push og ingen omgåelse av
readiness. Nye produkt-/arkitekturvalg skal stoppe kjeden.

Denne agentens konkrete delegering var bare 3.1: undersøk eksisterende grunnlag,
lag kortspec, implementer rene fire finansberegninger, test og overlever som
in-review/review med lokal commit. Uavhengig review eies av en ny agent via
hovedagenten. Baseline lest direkte fra Git:
`b143d4ba5e4efe48d040852065f64eda87cdc1cc`.

Hovedagentens inngangsbevis: hele Epic 2 er done; full regresjon kjørt etter
denne statusen har 582/582 Vitest, 89/89 bygget-app og 3/3 dev-E2E samt grønne
typecheck/lint/build. 1.4/1.5/1.7 er done. Ingen ny port eller beslutning.

BMAD-build ble aktivert med `uv run --no-cache` én gang og den genererte
workflowen lest. Manglende epic-3-context ble kompilert av én separat
sekvensiell kontekstagent; implementeringsagenten ventet uten egne filendringer
til denne var ferdig. Ingen andre underagenter eller samtidige redigerere.
Undersøkelse fant én nødvendig bakoverkompatibel detalj: eksisterende felles
validering sammenlignet alltid alle L/D/J-år; valgfri delmengde av årsfelt
gjenbruker samme regel for hvert nøkkeltall uten å endre standardkontrollen.

De fire låste formlene og egne feltavhengigheter er hele produksjonsscopet.
Yield beholder teller/nevner, beløp er eksakte desimalstrenger. Formler,
registrering, kilde, faktor, normalisering og kostnadsinnhold følger resultatet.
Ingen teknisk rapportstatus, KI, terskel, format, screening, snapshot eller UI
er bygget. Eksisterende P-/D-/J-definisjoner og kostnadsautoritet er gjenbrukt.

64 nye uavhengige finansprøver dekker Story 3.1 AC1–AC6 og relevant F1–F4/BT-fasit,
inkludert negative tall, måned/år, egne årsavhengigheter, hver inputmangel,
blank/null/ubekreftet/bekreftet null, kildekonflikt, kostnadsinnhold, eksakt
desimalaritmetikk og immutabilitet. Første målrettede kjøring av finance og de
to eksisterende valideringsfilene: 147/147 bestått. Typecheck og lint bestått.
Første fulle ueskalerte kjøring fikk sandboxens `listen EPERM 127.0.0.1` i HTTP-
prøvene (624 passerte/22 avledede feil). Autorisert identisk full kjøring ble
startet eskalert, uten kodeendring for miljøfeilen. Sluttbevis følger i
[storyverifikasjonen](../../implementation-artifacts/story-3-1-verifikasjon.md).

Promptkontekst og avgrensning er bevart her og i kortspecen; den aktive løpende
promptloggen `session-01a15dd1-ea82-76c3-b3af-fcca7dc42895.jsonl` holdes utenfor
commit etter hovedagentens instruks. Ingen hemmeligheter, nettverkskall mot KI,
eksterne meldinger eller push.

Sluttkontroll: 646/646 Vitest, 89/89 bygget-app, 3/3 dev-E2E,
typecheck/lint/build og diff-whitespace bestått. Scope er overlevert som
in-review/review; Epic 2 done og Epic 3 in-progress. Ingen uavhengig review
eller done-påstand fra implementeringsagenten. Neste steg er ny reviewer for
3.1; 3.2/3.3 er ikke startet.
